# CDIAT

### Condition Data Integration and Automation Toolkit

CDIAT is a modular software platform designed to integrate condition monitoring data with Computerized Maintenance Management Systems (CMMS/Openmaint), enabling automated maintenance, data analysis, and predictive maintenance capabilities.

The platform serves as a bridge between operational telemetry sources, maintenance management systems, and issue tracking platforms, allowing maintenance decisions to be driven by real-time equipment data instead of manual processes.

# Features

-Integration with Engineering Facility Database (EFD)
-Integration with OpenMaint CMMS
-Jira synchronization and automation
-Automated maintenance workflow execution
-Condition-based maintenance (CBM)
-Predictive maintenance (PdM) support
-Data visualization and analytics
-Machine learning model integration
-Modular and extensible architecture
